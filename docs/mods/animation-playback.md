# Animation pack playback

`SourceFrames` returns the component picture selected from source art. `PackFrames` adds optional resident animation samples, and defaults to `Original`. Installation validates a complete pack and every key before adding its pictures and its key map; it adds only the pack's own pictures, so its cost is the pack's size. Keys are folded (codes in lowercase, space padded), so table codes, file names and mod packs that spell a token differently select the same samples. Packs come only from files ([the bake](animation-generation.md)); nothing is generated during play. A v2 pack stores one motion vector and one accepted-fraction mask per source frame pair; the loader thread rebuilds each accepted picture from the source cel and the bake folder's `blend.lut`, with no motion search, colour math or gate decisions.

`Original` returns the source picture at every fractional phase. `Smooth` selects matching samples at fractions 64, 128 and 192 of each source interval, measured in 1/256 units. Each sample holds until the next quartile. A unit facing between the file's facings selects the samples of the file facing its source picture is drawn from. A missing or rejected sample falls back to the source picture. Source boundaries always select source art; a component file's boundary wrap cannot select a pack picture from a different direction.

The pose keeps its source frame number and exposes fractional progress separately. Objects and monsters use their mirrored animation counter; ordinary player modes follow their existing tick clock, and predicted locomotion follows its existing pose clock. Sequence poses supply no fractional phase. Neither source-frame selection nor world state advances for a generated sample. COF layer order remains the order of the starting source frame, and animation events remain on their simulation tick.

The synthetic regression sweeps two full source intervals: Original draw lists and composed SHA-256 image hashes match the source-only rules throughout. Smooth changes only the picture field, retains starting COF order, falls back for missing samples, and leaves the mirrored world unchanged. Determinism and 60 Hz rate baselines remain unchanged.
